# 三处蓄滞洪区位置调整（2026-09-23）

本次根据用户提供的三份文字位置资料，调整兰沟洼、南四湖湖东、宁晋泊的地图展示范围。附件中的制图建议作为位置线索使用；没有把参考点或乡镇界线当成法定边界，也没有将附件原文、地图截图或第三方原始文件加入仓库。

| 区域 | 调整后的空间关系 | 资料面积口径 |
| --- | --- | ---: |
| 兰沟洼 | 涿州东南部—高碑店—定兴的两河间低地；由原横向椭圆改为北端收窄、南部较宽的示意形态。 | 约 228 km² |
| 南四湖湖东 | 湖东堤以东的陆侧低地，按泗河—青山、界河—城郭河、新薛河—郗山三个河段分别显示；不再以椭圆覆盖南四湖水面。 | 滞洪面积 262.30 km²；研究中的总面积另有 252.69 km² 口径。 |
| 宁晋泊 | 北端参考洨河左堤，东侧参考老漳河左堤，南端在邢家湾附近与大陆泽相接；涵盖小宁晋泊、小南海、老小漳河区间的位置尺度。 | 总面积约 1034.82 km²；设计淹没面积 463.1 km²，不与总面积混用。 |

兰沟洼附件把涿州义和庄镇列作北部参考点。义和庄镇位于涿州东北部，与白沟河西侧、南拒马河北侧的两河夹持关系不一致，因此本次没有把它用作几何控制点。涿州段只作概略北伸，后续仍需主管部门图件核验。

三处范围均为自行绘制的低精度展示假设。折点没有堤轴、等高线或淹没测量依据；`geometryAreaSqKm` 是图示面积，`referenceAreaSqKm` 保留资料面积。南四湖湖东三段只标识陆侧走向，无法证明每一段都严格落在资料所述等高线以内。宁晋泊图形表达完整蓄滞洪区的大致位置，不能拿来判断某地块是否会被淹没。三处仍标记为 `estimatedBoundary: true`、`legalBoundary: false`，新图形未标记为项目所有者已验收。
